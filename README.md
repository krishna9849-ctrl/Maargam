# 🧭 Maargam (मार्गम्) • AI-Powered GIS Itinerary Hub

Maargam is a feature-rich, single-page web application that transforms travel planning into an interactive, real-time telemetry experience. By combining dynamic AI-grounded research with live geospatial mapping, Maargam allows users to source destinations, track their location, and visualize travel corridors using advanced GIS integration.

## 🚀 Key Features

* **Live AI Destination Sourcing:** Built-in AI engine that queries the web to fetch real-time pricing, environmental data, and authentic travel itineraries.
* **Interactive GIS Navigation:** Powered by **Leaflet.js**, featuring a draggable user position marker that computes real-time distances using the **Haversine Formula**.
* **Dynamic Sensor Feed:** Real-time simulation of atmospheric conditions (temperature, wind, humidity) with built-in "Real-Feel" calculations.
* **Tactical Navigation Pad:** Includes a manual joystick control system to simulate movement across the map for testing or exploration purposes.
* **Responsive UI:** A clean, modern interface built with Tailwind CSS, featuring smooth transitions, modals, and a "cyber-luxury" aesthetic.

## 🛠️ Technology Stack

* **UI Architecture:** Vanilla JavaScript, HTML5, and Tailwind CSS.
* **Mapping:** Leaflet.js with CartoDB Dark Matter/Voyager tiles.
* **AI Integration:** Google Gemini API with Grounding (Google Search tools).
* **Typography:** Google Fonts (Fraunces & Outfit).
